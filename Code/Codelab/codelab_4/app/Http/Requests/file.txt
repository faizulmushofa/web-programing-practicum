DTO (data transfer object) = 
- sebuah data yang di kirim ke client untuk menjaga agar tidak ada attribut privacy yang terkirim
- manipulasi request dan response agar sesuai dengan kebutuhan client
- menjaga keamanan data,karena DTO itu bersifat immutability(tidak dapat di ubah)

client(frontend) <------ api -----> backend(server)
