# Codelab 1 - Fundamental Pemrograman Web Modern

Codelab modul 1 — HTML Semantik + Tailwind CSS v4.

**Tema:** Modern Blue

## Tugas yang dikerjakan
1. Mengubah tema website menjadi **Modern Blue** menggunakan `@theme` di `main.css`
2. Melengkapi card section dengan konten: Anime, Manga, Light Novel (judul, deskripsi, gambar)

## Cara menjalankan

```bash
npm install
npm run watch
```

Buka `src/index.html` di browser (gunakan Live Server di VS Code).
